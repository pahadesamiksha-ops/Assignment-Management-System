# Assignment Management System

A console-based Assignment Management System developed using Java.

# Features

- Add assignments with titles and due dates.
- View all assignments with their IDs, due dates, and status.
- Mark assignments as Completed or Pending.
- Validate date input in `YYYY-MM-DD` format.
- Simple menu-driven interface.

# Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Time API (`LocalDate`)
- Scanner for user input

# How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Compile the Java file:
   javac AssignmentManagementSystem.java

5. Run the application:
   java AssignmentManagementSystem

# Concepts Demonstrated

- Conditional statements and loops
